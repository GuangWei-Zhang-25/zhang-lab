# AtlasCraft 2.0 verification

Verified locally on 7 October 2026, using Python 3.12.14 on macOS ARM64. This report concerns the reusable software implementation; it is not a new validation of anatomical accuracy or a rerun of every manuscript experiment.

- **118 automated tests and 12 subtests passed.** Coverage includes shifted/rotated and anisotropically sampled sections, exact transformed anchors, categorical integrity, nonuniform coordinates, small source components, inverse-warp safety fallback, bounded retries, source-path validation, input archive handling, provider errors and API request isolation.
- **Both API formats exercised through the complete pipeline using mocked HTTP responses.** OpenAI Responses and compatible Chat Completions each invoked all five required local stages. Credential strings did not appear in exported artifacts. No live provider account, model or paid API request was used.
- **Fresh install passed.** A wheel was installed into a separate virtual environment without system packages. The single-series and complementary-series workflows ran from the installed package, outside the source directory, with network connections blocked. See `INSTALL_VERIFICATION.json`; exact test-environment dependencies are in `requirements-tested.txt`.
- **Browser checks passed.** The local upload/example workflow completed and its downloadable ZIP passed CRC checks. The standalone viewer opened with `file://`, made no network requests, and supported actual WebGL rotation, zoom, pan, region isolation, native-label slice inspection, evidence display and surface download. Desktop and mobile layouts were inspected in Chromium. Other browsers and operating systems were not independently tested.
- **Synthetic alignment case passed.** Five deliberately shifted/rotated references produced a 17×128×128 volume. The adjacent-label geometric overlap objective improved from 0.456938 to 0.925103. Original inputs and all aligned anchors were preserved, and unresolved tissue remained marked. This is an engineering test, not a biological accuracy score.
- **Complementary-plane case passed.** The supplied-pose example produced a 25×40×40 common grid. Cross-plane contradictions stayed unresolved. Synthetic rotation tests verify world coordinates; order-permutation tests verify that unresolved inputs do not conceal disagreements among named labels.
- **Real-input smoke passed.** Three deliberately coarsened C1–C3 categorical maps from the existing frozen mouse atlas produced a 9×115×124 result with accepted shared-warp interpolation in both intervals. Source hashes, anchors, IDs and physical coordinates passed checks. Coarsening omitted a thin source ID in two maps and was explicitly recorded. These source data are not included in this release, and this small engineering smoke is not full-dataset validation.
- **Figure 1 schematic checked.** Editable SVG, embedded-font PDF and 300-dpi PNG were rendered and inspected. They depict the cooperative computational architecture; they contain no generated empirical anatomy or numerical benchmark plots.

The software performs bounded geometric self-correction. Expert anatomical acceptance remains open in every newly generated result. Preview surfaces can simplify small structures; native labels and explicit coordinates are the quantitative reference. The original source-specific spinal anatomical priors and all study benchmarks have not been generalized or rerun by this package.
