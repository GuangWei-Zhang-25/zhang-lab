The agent calls local tools and sees aggregate geometric measurements. Tokens stay in memory for this run; images, label names and source text are not sent. Your provider’s usage charges apply.

Input and reconstruction details

Every section must share the same pixel scale and canvas size. Use 0 for outside tissue and 65535 for unresolved tissue. The manifest records that identities, ordering, orientation and scale have been manually reviewed. Registration preserves originals; interpolation remains an inference.
