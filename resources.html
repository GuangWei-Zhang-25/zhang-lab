Equipment usage & instructions

Pipette puller P-97 — filament replacement, ramp test & longer taper

Materials used

Filament: FT330B.
Glass pipette: World Precision Instruments (WPI), item 504949; labeled “GLASS REPLACEMENT 1.14MM 3.5"”.

Filament replacement

Watch the filament replacement video: Installing a Filament

Run the filament ramp test

  1. After replacing the filament, press CLEAR.
  2. Press 0, then press 1 to run the ramp test.
  3. Read and record the ramp value displayed when the test finishes. The lab photo shows 295.
  4. Press RESET to return to the program, as indicated on the display.

295 is the result shown in this photo; record the value from your own test.

Longer taper: lab settings

The following settings worked for a longer taper in the lab using the FT330B filament and WPI glass listed above:

  1. Set HEAT to ramp + 14. With a ramp value of 295, use HEAT 309.
  2. Lower the air pressure to 300 using the steps below.
  3. Use a lower speed: 20 was used here.

Adjust the air pressure

  1. Press CLR.
  2. Press 0 to preserve the program.
  3. Press 2 for CHANGE AIR PRESSURE.
  4. Enter 300, then press ENTR.

Lock the program

  1. Press CLR, then 0 to preserve the program values.
  2. Press 7 for WRITE PROTECT.
  3. Select 1 to lock the program.
