Funder logo files for funding.html.

Drop each logo here with these exact filenames and the page picks it up
automatically. No code change needed: each card shows a typographic
wordmark until the matching file exists, then swaps to the image.

  whitehall-foundation.png

PNG with a transparent or white background works best. The logo band is
120 px tall and scales with object-fit: contain, so roughly 600-1200 px
wide is plenty. SVG also works: change the src extension in funding.html.
