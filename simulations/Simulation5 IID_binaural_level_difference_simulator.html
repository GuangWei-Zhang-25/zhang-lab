IID / ILD Binaural Level Difference Simulator

This demo isolates interaural intensity/level difference (IID/ILD): left vs right loudness mismatch with zero timing delay. Use it to teach the “head-shadow” cue used mainly for azimuth at higher frequencies.

Interpretation: ILD is defined here as L − R. Positive values make the left ear louder; negative values make the right ear louder. Internally we set levels as: L = base + ILD/2, R = base − ILD/2.
Tip: Use headphones. Start at a low level (e.g., -24 dB) and increase gradually. Avoid discomfort.
