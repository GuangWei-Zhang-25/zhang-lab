Automatic Hearing Sweep (Octave / Log) — 0 dB at bottom

• Frequency: 20 Hz → 32 kHz (octave/log2 mapping)
• Intensity: 0 to 70 dB in 10 dB steps (relative; not calibrated SPL)
• 5 s per level, auto-advances 0→10→…→70 dB (then stops)
• Hold Space while audible to mark segments
Important: “dB” here is relative digital level (dBFS-like), not true dB SPL. Actual loudness depends on your device, volume setting, headphones/speakers, and calibration. Start with low system volume.
This sets the top (70 dB) level; lower dB levels scale down exponentially.
Sequence: 0 → 10 → 20 → 30 → 40 → 50 → 60 → 70 dB, then stops. (Start is disabled while running to prevent accidental restarts.)
